## 2. 조직·시스템 명칭

- 본사 조직: 디지털계획처(데이터플랫폼부·AI인프라부), 교통센터(상황관리부), 시설처(구조물관리부), 도로처
- 지역본부 8개: 수도권 / 강원 / 충북 / 대전충남 / 전북 / 광주전남 / 부산경남 / 대구경북
- 내부 시스템(데모용 명칭)
  - **EXTIS** — 고속도로 교통정보시스템 (VDS·프로브 수집)
  - **EX-DataLake** — 전사 데이터 레이크 (5분 집계 적재)
  - **EXAM** — 도로자산관리시스템 (교량·터널 계측 이력)
  - **EXMMS** — 유지보수 작업관리 (작업지시서)
  - **RWIS** — 도로기상정보시스템 (노면온도·결빙)
  - **VMS** — 도로전광표지 (경보 송출)
  - 공개 채널: 고속도로 교통정보 `ROADPLUS`, 공식 도메인 `ex.co.kr`
